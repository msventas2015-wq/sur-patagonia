Exploración · isotipo cromático

Picos en color · merchandising

Isotipo picos aplicado sobre soportes físicos oscuros. Inspiración: isotipo abstracto recoloreable tipo Nike Swoosh, Gymshark, Arc'teryx. El isotipo es forma pura (sin texto), por eso admite color sin perder identidad. No es sistema oficial todavía — es una exploración para evaluación.

Criterio de lectura
Cada color se muestra sobre 2 fondos oscuros lado a lado: negro profundo #0f0e0c (izq.) y gris carbón #211e1a (der.). Sin glow, sin halo, sin degradado de luz. Corte limpio entre color y fondo. El veredicto indica en cuál(es) fondo(s) funciona cada color.

Sobre los mockups
Las ilustraciones son representaciones vectoriales (CSS) para evaluar pegada visual, no fotos reales del producto. Para presupuesto real de producción, se requieren fotos del producto con la aplicación ya impresa/bordada. Las versiones oficiales deben generarse desde archivos SVG/EPS vectoriales del isotipo, no desde filtros CSS.
